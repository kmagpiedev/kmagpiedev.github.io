PDF 편집기

여러 PDF를 합치고, 필요 없는 페이지를 지우고, 순서를 바꾸고, 회전하세요. 이미지를 PDF로 만들 수도 있습니다. 파일이 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

PDF나 이미지를 끌어다 놓거나 클릭해서 선택하세요
여러 개를 한꺼번에 올리면 순서대로 이어집니다 · PDF · JPG · PNG

여러 PDF와 이미지를 올려 합치고, 페이지를 삭제·회전·정렬해 하나의 파일이나 낱장 ZIP으로 저장합니다. 모든 작업은 서버 전송 없이 브라우저 안에서 처리되어 민감한 문서도 안전합니다. 암호가 걸린 PDF와 스캔본의 글자 수정은 지원하지 않습니다.

사용법

PDF 파일을 여러 개 올리면 모든 페이지가 한 줄로 이어져 표시됩니다. 페이지를 눌러 선택하고 회전하거나 삭제할 수 있고, 페이지 위에 마우스를 올리면 나타나는 화살표로 순서를 옮길 수 있습니다. 다 됐으면 하나의 PDF로 저장하거나, 선택한 페이지만 따로 뽑거나, 페이지마다 낱장으로 분리해 ZIP으로 받으세요.

이미지를 함께 올리면 각각 한 페이지로 변환되어 들어갑니다. 사진 여러 장을 PDF 한 파일로 묶어 제출해야 할 때 그대로 쓰시면 됩니다.

모든 처리는 브라우저 안에서 이루어집니다. 계약서나 신분증 사본처럼 민감한 문서도 외부로 나가지 않으며, 파일 크기 제한이나 하루 사용 횟수 제한도 없습니다.

작업방법
PDF 합치기합칠 파일을 원하는 순서대로 여러 개 올린 뒤 저장
PDF 나누기원하는 페이지만 선택해 "선택한 페이지만 저장"
페이지 삭제지울 페이지를 선택하고 삭제 후 저장
페이지 순서 변경페이지 위 화살표로 좌우 이동
페이지 회전선택 후 왼쪽·오른쪽 회전 (90도 단위)
낱장으로 분리"페이지별로 분리"로 페이지마다 파일 생성
이미지를 PDF로JPG·PNG를 올리면 자동으로 페이지가 됩니다

자주 겪는 문제

암호가 걸린 PDF는 열리지 않아요

열기 암호가 설정된 파일은 브라우저에서 해독할 수 없습니다. 암호를 알고 계시면 뷰어에서 열어 인쇄 기능으로 새 PDF를 만든 뒤 그 파일을 올려주세요.

스캔한 문서의 글자를 편집하고 싶어요

이 도구는 페이지 단위 편집만 지원합니다. 스캔본은 글자가 아니라 이미지라서 텍스트 수정이 되지 않고, 그러려면 별도의 문자 인식 과정이 필요합니다.

파일이 너무 커서 느려요

페이지 수가 아주 많은 문서는 미리보기를 만드는 데 시간이 걸립니다. 미리보기가 다 뜨기 전에도 편집과 저장은 정상 동작하니 잠시 기다려 주세요.

저장한 파일 용량이 원본보다 커요

페이지를 재조립하는 과정에서 일부 최적화가 풀릴 수 있습니다. 용량을 줄이셔야 한다면 이미지 용량 줄이기로 사진을 먼저 줄인 뒤 PDF로 만드시는 편이 효과적입니다.
