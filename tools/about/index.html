까치툴 소개

English version

브라우저에서 끝내는 무료 도구 모음 — 회원가입 없이, 파일 전송 없이.

공구를 든 까치가 까치툴의 마스코트입니다. 까치가 좋은 소식을 물어다 주듯, 귀찮은 일을 대신 처리해 주는 도구를 모았습니다.

까치툴은 이런 곳입니다

까치툴은 일상에서 자주 필요한 작업 — 이미지 편집, PDF 처리, 급여·세금 계산, 날짜 변환 같은 일 — 을 프로그램 설치나 회원가입 없이 웹 브라우저에서 바로 해결할 수 있게 만든 도구 모음입니다. 현재 이미지, PDF·문서, 금융·급여, 생활 계산, 타자·반응 테스트 분야의 도구 45종을 한국어로 제공하고 있고, 그중 일부는 영어판으로도 쓸 수 있습니다.

지키는 원칙

서버 전송 없음회원가입 없음워터마크 없음전부 무료

가장 중요한 원칙은 파일이 사용자의 브라우저를 떠나지 않는다는 것입니다. 이미지 압축도, PDF 서명도, 배경 제거의 AI 모델 구동까지도 전부 사용자의 기기 안에서 처리됩니다. 서버로 업로드하는 단계 자체가 없기 때문에, 신분증 사본이나 계약서처럼 민감한 파일도 외부 유출 걱정 없이 다룰 수 있습니다. 같은 이유로 한 번 열어 본 도구는 인터넷이 끊겨도 동작하고, 크롬에서는 까치툴을 앱으로 설치해 쓸 수도 있습니다.

도구가 내놓는 계산 결과는 법령과 공식 요율표를 근거로 만들지만 참고용 추정치입니다. 어떤 근거로 계산하는지는 각 도구 페이지 하단과 면책조항에 정리되어 있습니다.

만드는 사람

까치툴은 1인 개발자가 만들고 운영합니다. 게임과 앱을 만들어 온 개발자 케이맥파이(K-magpie)가 "이런 건 왜 죄다 가입을 요구하지?" 싶었던 도구들을 하나씩 직접 만들면서 시작됐습니다. 지금도 새 도구를 계속 추가하고 있고, 기존 도구도 사용자 피드백을 받아 다듬고 있습니다. 만세력·운세 콘텐츠는 자매 사이트 야옹명리에서 따로 운영합니다.

어떻게 만들고 검증하나

도구 하나를 올리기 전에 세 가지를 거칩니다. 첫째, 계산 도구는 근거가 되는 법령·고시·공식 산식을 페이지 본문에 그대로 적고, 그 산식으로 만든 기대값 표와 실제 출력을 자동 대조합니다. 연봉 실수령액 계산기는 국세청 간이세액표 588행을 전부 대조했고, 만세력은 1900년부터의 절입 시각을 분 단위로 검사했습니다. 둘째, 파일 도구는 브라우저 밖으로 나가는 요청이 하나도 없는지 네트워크 로그로 확인합니다. 배경 제거·화질 개선·글자 추출처럼 AI 모델을 쓰는 도구도 모델 파일을 이 사이트에서 내려받아 기기 안에서만 돌립니다. 셋째, 모바일 화면(390px)에서 가로 스크롤이 생기지 않는지, 다크 모드에서 글자가 묻히지 않는지 스크린샷으로 봅니다. 이 과정을 통과하지 못한 도구는 올리지 않고, 통과했더라도 근거가 흔들리는 영역(부동산 세금, 연말정산처럼 개인 사정에 따라 답이 갈리는 계산)은 아예 만들지 않거나 제공을 종료했습니다.

분야별로 무엇이 있나

이미지 — 배경 제거, AI 화질 개선, 증명사진, 크기 조절, 확장자 변환, 용량 줄이기, 이어붙이기, 위치정보 지우기, 워터마크, GIF, 짤 만들기. 전부 업로드 없이 기기 안에서 처리됩니다.

PDF·문서 — 합치기·나누기, 용량 줄이기, 서명·도장, PDF를 이미지로, 이미지를 PDF로, 사진 글자 추출. 계약서나 신분증 사본처럼 밖으로 보내고 싶지 않은 문서를 위해 만들었습니다.

급여·노동·금융 — 연봉 실수령액, 퇴직금, 실업급여, 연차, 주휴수당, 대출 이자, 예금·적금, 물타기 평단가. 계산 과정과 근거 조문을 함께 보여주고, 결과는 참고용 추정치라는 점을 페이지마다 밝힙니다.

생활·학습·재미 — 전기요금, 유류비, 평수, 퍼센트, BMI, 학점, 날짜·만 나이, 음력 변환, 만세력, 글자수, QR코드, 회의록, 인스타 줄바꿈·글꼴, 타자 속도, 반응속도, 음악 자르기, 그리고 앱 개발자용 아이콘·스토어 스크린샷 생성기.

정확도와 한계

까치툴의 계산은 공개된 규칙을 그대로 코드로 옮긴 것이지, 개인의 사정을 아는 전문가의 판단이 아닙니다. 같은 연봉이라도 비과세 항목이나 부양가족 수에 따라 실수령액이 달라지고, 같은 입사일이라도 회사의 회계연도 규정에 따라 연차가 달라집니다. 그래서 각 도구는 "무엇을 가정했는지"를 결과 옆에 적어 두고, 가정이 다르면 직접 바꿔 넣을 수 있게 입력란을 열어 두었습니다. 법령이 바뀌면 페이지 상단의 연도 표기와 산식을 같이 고치며, 바꾼 날짜는 본문에 남깁니다. 어떤 도구도 법률·세무·의료 자문을 대신하지 않으며, 금액이 걸린 결정은 반드시 해당 기관이나 전문가에게 확인하시기 바랍니다.

자주 묻는 질문

정말 파일이 서버로 안 가나요? 네. 페이지를 연 뒤 인터넷을 끊어도 도구가 그대로 동작하는 것으로 확인할 수 있습니다. 브라우저 개발자 도구의 네트워크 탭을 열어 두고 써 보셔도 됩니다.

왜 무료인가요? 페이지에 붙는 광고가 유일한 수익입니다. 유료 플랜, 회원가입 유도, 워터마크 해제 결제 같은 것은 없고 앞으로도 두지 않을 생각입니다.

결과가 다른 사이트와 다릅니다. 대부분 가정의 차이입니다. 어떤 요율과 조건을 썼는지 페이지 하단의 계산 근거를 다른 사이트의 안내와 나란히 비교해 보세요. 우리 쪽 오류라면 아래 주소로 알려주시면 고칩니다.

영어·일본어 버전도 있나요? 한국에서 일하는 외국인을 위해 급여·노동 계산기와 이미지·PDF 도구 일부를 영어로 제공합니다. 까치테스트는 영어와 일본어로도 볼 수 있습니다.

제공을 종료한 도구가 있나요? 있습니다. 부동산 취득세·중개수수료·전월세 전환율 계산기와 개인정보처리방침 생성기는 개인 사정이나 법적 책임에 따라 답이 갈리는 영역이라 제공을 종료했고, 해당 주소에는 안내만 남겨 두었습니다.

오류 제보와 제안

계산이 이상하거나 도구가 제대로 동작하지 않으면 support@kmagpie.com으로 알려주세요. "이런 도구도 있었으면 좋겠다"는 제안도 언제나 환영합니다. 실제로 지금 있는 도구 중 여럿이 그런 제안에서 나왔습니다.
