이미지 확장자 변환

PNG · JPG · WebP · BMP · ICO를 서로 바꿉니다. 여러 장을 한꺼번에 변환하고 ZIP으로 받으세요. 파일이 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

이미지를 여기에 끌어다 놓거나 클릭해서 선택하세요
여러 장 동시 선택 가능 · PNG · JPG · WebP · AVIF · GIF · BMP · SVG · ICO

형식만 바꾸는 게 목적이라면 90 이상을 쓰세요. 용량을 줄이는 게 목적이면 이미지 용량 줄이기가 목표 용량에 맞춰 자동으로 조절해 줍니다.

흰색

JPG와 BMP는 투명도를 저장하지 못합니다. 원본에 투명한 부분이 있으면 이 색으로 채워집니다.

ICO 한 파일 안에 여러 해상도를 함께 담습니다. 웹사이트 파비콘이면 16·32·48로 충분해요.

px

비율은 그대로 유지되고, 원본보다 커지지는 않습니다. 단계적으로 축소해서 계단 현상 없이 매끄럽게 줄입니다.

파일 이전이후

PNG·JPG·WebP·BMP·ICO 사이를 여러 장 한꺼번에 변환하고 ZIP으로 받을 수 있습니다. 변환은 전부 브라우저 안에서 일어나 파일이 서버로 올라가지 않습니다. 제출용은 JPG, 웹용은 WebP, 투명 배경이 필요하면 PNG가 무난한 선택입니다.

사용법

이미지를 여러 장 올린 뒤 바꿀 형식을 고르고 변환하기를 누르면 됩니다. 결과는 파일별로 표시되고 하나씩 받거나 ZIP으로 한 번에 받을 수 있습니다. 원본은 건드리지 않고 새 파일이 만들어지므로, 결과가 마음에 안 들면 설정을 바꿔 다시 누르면 됩니다.

모든 변환은 브라우저의 Canvas API로 이루어집니다. 파일이 서버로 올라가지 않기 때문에 개인 사진이나 공개 전 자료도 안심하고 쓰실 수 있고, 업로드·다운로드를 기다릴 필요가 없어 수십 장도 금방 끝납니다. 사용 횟수 제한이나 워터마크도 없습니다.

어떤 형식으로 바꿔야 하나요

PNG

투명 배경이 필요하거나, 로고·아이콘·스크린샷처럼 글자와 경계선이 또렷해야 하는 이미지에 씁니다. 무손실이라 몇 번을 다시 저장해도 화질이 나빠지지 않습니다. 대신 사진을 PNG로 저장하면 JPG보다 용량이 몇 배 커집니다.

JPG

사진에 가장 적합하고 어디서나 열립니다. 상대방 환경을 모를 때, 오래된 프로그램에 넣어야 할 때, 관공서나 학교 서식에 첨부할 때 안전한 선택입니다. 투명도를 지원하지 않아서 투명한 부분은 위에서 고른 색으로 채워집니다.

WebP

같은 화질 기준으로 JPG보다 25~35% 작으면서 투명도까지 지원합니다. 웹사이트에 올릴 이미지라면 대부분 이게 정답입니다. 다만 오래된 프로그램이나 일부 문서 편집기, 관공서 업로드 창에서는 안 열릴 수 있으니 제출용 파일은 JPG로 두세요.

BMP

압축을 전혀 하지 않는 형식이라 용량이 아주 큽니다. 일부 산업용 장비 소프트웨어나 오래된 프로그램이 BMP만 받는 경우에 쓰세요. 일반적인 용도로는 권장하지 않습니다.

ICO

웹사이트 파비콘과 윈도우 프로그램 아이콘에 쓰는 형식입니다. 한 파일 안에 여러 해상도를 함께 담을 수 있어서, 브라우저 탭에서는 16px을, 바탕화면 바로가기에서는 48px을 골라 쓰는 식으로 동작합니다. 정사각형이 아닌 이미지를 넣으면 비율을 유지한 채 가운데 정렬되고 남는 부분은 투명하게 채워집니다.

아이폰 HEIC 사진은요

아이폰이 기본으로 저장하는 HEIC은 브라우저가 아직 읽지 못해서 이 도구에서 변환할 수 없습니다. 사파리를 제외한 대부분의 브라우저가 마찬가지예요. 다만 아이폰 쪽 설정을 한 번만 바꿔두면 앞으로 찍는 사진이 JPG로 저장되니 이게 더 확실한 해결책입니다.

설정 → 카메라 → 포맷 → 높은 호환성을 고르세요. 이미 찍어둔 HEIC 사진은 설정 → 사진 → 맨 아래 "MAC 또는 PC로 전송" → 자동으로 바꾼 뒤 케이블로 옮기면 아이폰이 알아서 JPG로 변환해서 보내줍니다.

자주 겪는 문제

투명 배경이 흰색으로 바뀌었어요

JPG나 BMP로 바꾸셨을 가능성이 높습니다. 두 형식은 투명도를 저장하지 못합니다. 투명 배경을 유지하려면 PNG나 WebP를 고르세요. 흰색 말고 다른 색으로 채우고 싶다면 색상 선택 상자에서 바꿀 수 있습니다.

GIF를 올렸더니 움직임이 사라졌어요

첫 번째 장면만 이미지로 가져옵니다. 움직이는 GIF를 그대로 유지하는 변환은 지원하지 않아요.

PNG로 바꿨더니 용량이 훨씬 커졌어요

정상입니다. PNG는 무손실이라 사진을 담으면 JPG보다 몇 배 커집니다. 사진은 JPG나 WebP로 두시고, PNG는 투명도가 필요하거나 글자·도형이 많은 이미지에만 쓰세요.

변환한 파일을 특정 사이트에 올렸더니 거부돼요

WebP나 BMP를 받지 않는 곳이 아직 많습니다. 업로드용이라면 JPG로 다시 변환해 보세요. 용량 상한 때문에 거부된 거라면 이미지 용량 줄이기에서 목표 용량을 지정해 맞출 수 있습니다.
