# GYEOL: VEINS OF LIGHT

Dream Big Art Awards 출품을 목표로 제작한 K-MAGPIE의 60초 실시간 프로시저럴 미디어아트입니다.

- 작품명: 결: 빛의 맥
- 영문명: GYEOL: VEINS OF LIGHT
- 제작 방식: Raw WebGL 2, GLSL, Web Audio API
- 외부 패키지: 없음
- 기본 화면: 16:9
- 언어: 한국어, 영어, 일본어

일반 감상은 `index.html`, 녹화는 `?capture=1`, 키프레임 검수는 `?frame=초&capture=1`을 사용합니다.
