# 결: 빛의 맥 — 렌더링 최적화

## 구조

- 외부 런타임과 CDN이 없는 단일 WebGL 2 작품
- 모든 형상은 고정 시드 기반으로 시작 시 한 번 생성
- 배경 1회 전체 화면 셰이더 패스
- 꽃살문·오방빛·매듭·연화문은 장면별 단일 리본 메시로 병합
- 별·빛 조각·깃털·꽃잎은 GPU 인스턴싱 또는 포인트 렌더링
- 이미지·영상·3D 모델 파일을 사용하지 않아 초기 전송량과 메모리 사용 절감
- 숨겨진 탭에서는 렌더 업데이트와 오디오를 정지

## 품질 단계

| 단계 | 대상 | 특징 |
|---|---|---|
| low | 저사양 모바일 | 낮은 DPR, 정적 필름 그레인, 최소 파티클과 기하 세그먼트 |
| medium | 일반 모바일·노트북 | 균형형 파티클 수, 0.93 내부 렌더 스케일 |
| high | 일반 데스크톱 | 고밀도 깃털과 별, 1.0 렌더 스케일 |
| ultra | 캡처용 고성능 환경 | 더 높은 DPR과 형상 밀도 |

일반 실행에서는 포인터 종류, 화면 폭, 논리 코어 수, 기기 메모리를 기준으로 초기 품질을 선택한다. 약 2.6초 간격으로 프레임 시간을 평가해 내부 렌더 스케일을 단계적으로 내리거나 회복한다. 전시·녹화 모드에서는 해상도를 고정해 프레임 간 화면 크기가 바뀌지 않게 한다.

## URL 옵션

- `?quality=low|medium|high|ultra` 품질 강제
- `?capture=1` UI를 숨기고 60초 자동 재생
- `?frame=38&capture=1` 지정 시점 정지 렌더
- `?debug=1` 품질·내부 해상도·장면 파라미터 확인
- `?lang=ko|en|ja` 언어 강제
