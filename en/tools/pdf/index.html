How to use

Add one or more PDF files and every page lines up in a single strip. Click a page to select it, then rotate or delete it; hover over a page and the arrows that appear let you move it left or right. When you're done, save everything as one PDF, pull out just the selected pages, or split the document into single-page files delivered as a ZIP.

Add images alongside your PDFs and each one becomes a page of its own — exactly what you need when a form asks for several photos combined into a single PDF.

All processing happens inside your browser. Contracts, ID scans and other sensitive documents never leave your device, and there is no file size cap or daily usage limit.

Why "no upload" matters

Most popular online PDF sites work by sending your file to their servers, processing it there, and sending the result back. You have no way of knowing how long your document sits on those servers or who can see it — a real concern when the file is a contract, a scan of your passport, or medical paperwork, and often a breach of company policy for work documents.

This tool takes the other approach: the PDF is read, edited and reassembled entirely inside your browser. Nothing is transmitted anywhere — it even keeps working with your internet connection switched off.

Troubleshooting

A password-protected PDF won't open

Files locked with an open password can't be decrypted in the browser. If you know the password, open the file in a PDF viewer and use its print function to save an unprotected copy, then add that copy here.

I want to edit the text of a scanned document

This tool works on whole pages only. A scan stores pictures of letters rather than actual text, so the characters can't be edited — that would require a separate OCR step.

Large files feel slow

Documents with a lot of pages take a while to build previews. Editing and saving work normally even before every preview has appeared, so feel free to keep going.

The saved file is larger than the original

Reassembling pages can undo some of the original file's internal optimisation. If you need the result smaller, run it through the PDF compressor, which shrinks a file to a target size like 2MB or 5MB.
