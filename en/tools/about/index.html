What this site is

K-magpie Tools is a collection of everyday utilities — image editing, PDF handling, converters and calculators — built to work right in your web browser, with nothing to install and no account to create. The English collection currently covers images, PDFs and everyday utilities, plus a set of calculators for people working in Korea. The full collection (30+ tools) is available in Korean.

The principles

No uploadNo sign-upNo watermarkFree

The most important one: your files never leave your browser. Image compression, PDF signing, even the AI model behind background removal — everything runs on your own device. There is simply no upload step, which means sensitive files like ID scans and contracts can be handled without ever leaving your machine. It also means a tool keeps working once loaded, even offline, and on Chrome you can install the whole toolset as an app.

Calculator results are estimates based on official rates and regulations, for reference only. What each tool is based on is explained at the bottom of its page and in the disclaimer.

Who builds it

K-magpie Tools is built and run by a single indie developer — K-magpie — who also makes games and mobile apps. It started with a simple annoyance: "why does every one of these tools demand an account?" New tools are added regularly, and existing ones keep getting refined based on user feedback.

Bug reports and suggestions

If a calculation looks wrong or a tool misbehaves, email support@kmagpie.com. Suggestions for new tools are always welcome — several tools on this site started as one.
