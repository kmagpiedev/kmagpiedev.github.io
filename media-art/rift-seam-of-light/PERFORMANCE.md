# 성능 설계

## 렌더 구조
- WebGL 2 단일 렌더러. 대체 작품(fallback)은 사용하지 않는다.
- 외부 런타임·CDN·Base64 조립·동적 eval을 사용하지 않는다.
- 정적 프로시저럴 데이터는 시작 시 한 번만 생성한다.
- 꽃살문, 오방 빛실, 까치 깃털, 매듭 다리, 단청 연화문은 인스턴싱으로 묶는다.
- 장면 컬러 + 반해상도 블룸 + 합성의 고정 패스 구조를 사용한다.
- 매 프레임 새 배열·객체 생성을 피하고 TypedArray와 행렬 버퍼를 재사용한다.

## 품질 단계
- High: 최대 DPR 1.5, 15,000 미세 입자, 블룸 2회.
- Medium: 최대 DPR 1.25, 9,000 미세 입자, 블룸 1회.
- Low: 최대 DPR 1.0, 5,500 미세 입자, 블룸 1회.
- Auto: 기기 메모리·코어·화면 크기로 초기 단계를 선택하고, 평균 프레임 시간이 높으면 내부 해상도만 단계적으로 낮춘다.

## 캡처 모드
- `?capture=1`은 UI와 포인터를 숨기고 60초를 자동 재생한다.
- `?render=1920x1080`처럼 내부 렌더 크기를 고정할 수 있다.
- `?frame=34`는 해당 시점을 정지 렌더해 키프레임 검수에 사용한다.
- 모든 난수는 고정 시드이므로 재생마다 형상과 구도가 동일하다.
